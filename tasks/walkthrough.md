# Разделение MDD на Daily и Global

## 1. Изменения в `src/parser.py`
Добавлена поддержка индекса экспирации (`Expiry_Idx`) в функцию парсинга `parse_cme_pdf`.  
Так как страйки в PDF-бюллетенях отсортированы по возрастанию для каждой экспирации, мы отслеживаем падение (reset) значения страйка (`strike < last_strike - 0.005`). При каждом таком сбросе `expiry_idx` увеличивается, позволяя отличать краткосрочные внутридневные опционы (`Expiry_Idx == 0`) от глобальных серий. Это значение записывается в результирующий словарь данных.

## 2. Изменения в `main.py`
Функция `calculate_gex_pipeline` была переписана для разделения данных.
Вместо одного абсолютного значения для Settlement Price и Open Interest (OI), логика теперь фильтрует DataFrame:
- `daily_df`: Данные только для `Expiry_Idx == 0`.
- `global_df`: Данные для `Expiry_Idx > 0`.
Для каждой группы рассчитывается страйк с максимальным OI (отдельно для Call и Put). 
Результаты объединяются (через `merge`) с суммарными GEX и Abs_Gamma по каждому страйку. В итоговый CSV-файл записываются 8 новых колонок для премий и открытого интереса: `Daily_Call_OI`, `Daily_Call_Settle`, `Global_Call_OI` и так далее. 

## 3. Изменения в `CME_GEX_Levels_EA.mq5`
- **Структуры и парсинг**: `OptionRow` была расширена для хранения Daily и Global значений. Функция `ParseCSV` читает новые колонки, а также рассчитывает максимальный OI по 4 отдельным направлениям: `Daily Call`, `Daily Put`, `Global Call`, `Global Put`.
- **Отрисовка уровней MDD**:
  - Для **Daily MDD** рисуется пунктирная линия с суффиксом "_DCMD" / "_DPMD".
  - Глобальные MDD `G_CALL`/`G_PUT` больше не рассчитываются и не рисуются; для месячной структуры остаются только уровни `GLOB CALL` / `GLOB PUT`.
  - Тултипы расширены для отображения объемов OI как для Daily, так и для Global контрактов на данном страйке.
- **Отрисовка 1st Order**: 
  - Добавлено разделение на глобальные рыночные границы (`[GLOB CALL]/[GLOB PUT]`) и внутридневные границы (`[DLY CALL]/[DLY PUT]`).

## 4. Тестирование
Скрипт `main.py` успешно прошел выполнение и сгенерировал корректные файлы для EUR и GBP с новыми колонками (16 колонок в итоговых CSV). Код EA синтаксически корректен и использует правильные методы MQL5 для работы с линиями тренда и текстом.

## Стабилизация смещения исторических уровней (fw_offset)
- **Проблема:** При загрузке уровней за предыдущие дни `iBarShift` на таймфрейме `PERIOD_D1` возвращал ошибку `-1`, так как история дневного таймфрейма не была загружена в терминале. Это обнуляло `fw_offset` и сдвигало уровни (особенно заметно на EURUSD и Gold из-за больших форвардных разниц).
- **Решение:**
  1. В `GetDailySpotReferenceWithRetry` добавлена принудительная синхронизация D1-истории для конкретной даты через `CopyTime(symbol, PERIOD_D1, time_val, 1, temp)` на каждой итерации.
  2. Реализован резервный метод (fallback): если D1-история не отвечает, индикатор берет Open-цену первой свечи дня с текущего таймфрейма графика (`_Period`), который гарантированно загружен.
- **Результат:** Зоны R68-R95 и уровни за все предыдущие дни теперь сдвигаются абсолютно точно на всех валютных парах, золоте, индексах и криптовалютах. MQL5 бинарники успешно перекомпилированы.

## Добавление валютной пары USDCAD в индикатор и дашборд
- **Реализовано:**
  1. **Парсинг CAD на CME**: В `src/parser.py` добавлено масштабирование страйков (`/10000.0`) и премий (`/100.0`) при обнаружении канадского доллара (CAD).
  2. **Математическое преобразование CADUSD -> USDCAD (Reciprocal Option Conversion)**:
     - Рассчитывается обратный спот: $Spot_{USDCAD} = 1 / Spot_{CADUSD}$
     - Рассчитывается обратный страйк: $Strike_{USDCAD} = 1 / Strike_{CADUSD}$
     - Типы опционов инвертируются (Calls -> Puts, Puts -> Calls).
     - Премия пересчитывается по формуле паритета: $Settle_{USDCAD} = Settle_{CADUSD} / (Strike_{CADUSD} \times Spot_{CADUSD})$.
  3. **Маршрутизация файлов**: Сгенерированный CSV сохраняется как `GEX_USDCAD_YYYY-MM-DD.csv` и копируется в отдельную подпапку `Files/GEX/USDCAD/` терминала MT5.
  4. **Индикатор**: В `CME_GEX_Levels_Indicator.mq5` добавлена поддержка символа CAD, настроены пути поиска локального кэша в папке `USDCAD\` и удаленного скачивания по имени файла `GEX_USDCAD_date.csv`. Индикатор перекомпилирован в `.ex5` без ошибок и предупреждений.
  5. **Дашборд**: Интегрирована вкладка `USDCAD`, обновлен бэкенд `run_dashboard.py` для поиска файлов USDCAD и отдачи дат/JSON, на фронтенде `app.js` скорректировано форматирование лейблов и файлов экспорта для исключения дублирования `USDCADUSD`.
